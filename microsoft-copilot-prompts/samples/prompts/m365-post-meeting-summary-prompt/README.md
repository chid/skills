# 🚀 Post meeting summary  📅

![Demo of summary generated by copilot](./assets/demo.png)

## Summary

## Prompt 💡

 [Insert meeting] Generate Post-Meeting Summary: “What questions were asked, answered, and unresolved?”.

## Description ℹ️

Find out the context of the meeting and extract important points

## Instructions 📝

1. Make sure you have copilot for Microsoft 365 in your tenant
2. Go to Copilot app in Teams
3. Copy paste the above prompt and replace [Insert meeting] with reference to the meeting using copilot reference feature

### Improvise Usage 🚀
Suggest to create an email to follow up unresolved questions.



## Prerequisites

* [Copilot for Microsoft 365](https://developer.microsoft.com/microsoft-365/dev-program)
